## Decision: scope interpretation

The presets were deliberately removed from main in `56c6451` ("drop the bundled dataset and preset dropdown"). The FOREMAN recon confirms the requested behavior already substantially exists:

- `src/lib/graphLoader.ts:182-192` — `loadGraph()` parses `built_at_commit` into `stats.commit` (truncated to 8 chars), and computes `stats.nodes`, `stats.links`, `stats.communities` from the parsed graph.
- `src/app/page.tsx:57-64` — header renders all four stats (`nodes`, `links`, `communities`, `commit`) for ANY loaded graph via drag-drop or file picker.
- Existing tests already assert metadata exposure: corpus test at `graphLoader.test.ts:39-45` checks stats/commit against a real graph; synthetic tests at lines ~181-205 cover commit-absent fallbacks.

Restoring a bundled preset would re-add a dataset that was intentionally dropped one commit ago — that reverses a settled product decision with no instruction to do so. The spec's acceptance floor ("existing vitest suite still passes + loader exposes metadata") confirms intent: this card verifies/hardens the existing metadata path, not a preset restore.

**Scope = loader exposes metadata + header shows it for any loaded graph. No preset restoration.**

describe("loadGraph — metadata for header", () => {
  it("exposes node and edge counts plus build commit", () => {

    expect(stats.nodes).toBe(3);
    expect(stats.links).toBe(2);
    expect(stats.commit).toBe("abc1234"); // fixture ships built_at_commit
  });

  it("counts edges supplied under the legacy `edges` key", () => {
    const raw = JSON.parse(fixture());
    raw.edges = raw.links;
    delete raw.links;
    expect(loadGraph(JSON.stringify(raw)).stats.links).toBe(2);
  });

  it("renders an em-dash placeholder when commit is absent", () => {
    // documents the page.tsx contract: `graph.stats.commit || "—"`
    const raw = JSON.parse(fixture());
    delete raw.built_at_commit;
    const { stats } = loadGraph(JSON.stringify(raw));
    expect(stats.commit).toBe("");
    expect(stats.commit || "—").toBe("—");
  });
});
